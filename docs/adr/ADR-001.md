# ADR-001: Uso de Docker Compose como plataforma de despliegue
Estado: Accepted
Fecha: 2026-06-04
Autores: Elevel
## Contexto
Se requiere desplegar Odoo 17 Community junto con PostgreSQL y Nginx en un servidor bare-metal de hardware repropuesto con Debian 12 (mixtli), con recursos limitados y sin equipo de operaciones dedicado. El entorno de producción debe ser reproducible, aislado y operable por una sola persona.## Decisión
Se utilizará Docker Compose para orquestar los servicios de Odoo, PostgreSQL y Nginx en el servidor mixtli.
## Alternativas consideradas
Alternativa y Razón de descarte
Binario + venv:	Gestión manual de dependencias del sistema, difícil reproducibilidad entre entornos y sin aislamiento de servicios.
Kubernetes (k3s/kubeadm):	Overhead operacional excesivo para una sola instancia. Curva de aprendizaje no justificada para este alcance.
Podman + Podman Compose:	Menor ecosistema de documentación para Odoo. Equipo sin experiencia en la tecnologia.
## Consecuencias
- Aislamiento de servicios: cada componente (Odoo, PostgreSQL, Nginx) corre en su propio contenedor con dependencias definidas.
- Reproducibilidad garantizada mediante docker-compose.yml versionado en Git.
- Compatible con el conocimiento previo del operador y con la documentación oficial de Odoo.
- El daemon de Docker corre como root; requiere configuración adicional de seguridad (usuarios sin privilegios, volúmenes con UID correcto).
